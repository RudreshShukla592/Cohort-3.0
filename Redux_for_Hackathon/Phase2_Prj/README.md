# Student Management System

🔗 **Documentation:** _(https://app.notion.com/p/Redux-Toolkit-Documentation-3a8bfb9ca2ad809db0e3df7e8aa2ef5b?source=copy_link)_

---

A simple CRUD application built with **React** and **Redux Toolkit** to learn centralized state management.

## Features

- ➕ Add Student
- ✏️ Update Student
- 🗑️ Delete Student
- 💾 Local Storage Persistence

## Tech Stack

- React
- Redux Toolkit
- React Redux
- React Hook Form
- Tailwind CSS
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```
